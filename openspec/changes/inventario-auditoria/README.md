# inventario-auditoria

Auditoría de inventario físico vs sistema por personal externo, con bloqueo
híbrido de movimientos, conteo ciego, reconteo y reporte por sucursal/bodega,
marca, SKU y fecha.

Estado: fases 1–5 implementadas con pruebas automatizadas; falta prueba
manual en navegador y MySQL real.

Consultar [propuesta](proposal.md), [diseño](design.md) y [tareas](tasks.md).
