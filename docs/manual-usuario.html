Manual de Usuario - AgroSys

AgroSys es un sistema de inventario, ventas y administración para negocios agrícolas construido con Laravel y Vue 3.

Las capturas de pantalla mostradas son ilustrativas.

Acceso

  1. Visita / para la pantalla de inicio de sesión.
  2. Tras autenticarte, se muestra el panel principal en /dashboard.

Módulos principales

Inventario

  1. Accede al listado de inventario en /inventario para gestionar productos.
  2. Para agregar un producto utiliza /inventario/addInventario.
  3. Consulta los catálogos de clasificación, enfermedad, tipo de flor y marca según necesites.

Ventas y Devoluciones

  1. Gestiona ventas en /venta.
  2. Genera tickets en /ticket/{venta}.
  3. Maneja devoluciones desde /venta/devoluciones/index.

Clientes y Pedidos

  1. Administra clientes en /cliente.
  2. Registra pedidos internos en /pedidos/index.

Administración

  1. Gestiona empresas en /empresa.
  2. Administra usuarios en /usuario.
  3. Controla sucursales en /sucursal, incluyendo el ancho del ticket térmico.

Reportes

  1. Accede al panel de reportes en /reporte.
  2. Genera reportes de ventas, inventario y ventas por producto o marca, con versiones para impresión térmica.

Compras, Facturas y API

  1. Registra compras en /compra.
  2. Administra facturas en /facturas/index.
  3. Consulta la API pública para sucursales, productos y pedidos mediante la cabecera X-API-KEY.

Roles y seguridad

Cada ruta está protegida por roles (vendedor, inventario, admin y superAdmin). Asegúrate de disponer del rol adecuado para acceder a cada módulo.

Soporte

Para más información consulta la documentación Swagger disponible en /api/documentation.
